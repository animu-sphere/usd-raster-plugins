# v0.1.0

Released 2026-08-27.

## Scope

The first release establishes the OpenUSD-free geospatial/raster value model,
GeoTIFF metadata reader, and registered `.tif` / `.tiff` FileFormat plugin. The
aggregate product installs a component-owned probe and generated basic fixture
for composed-runtime acceptance.

## Supported behavior

- Classic TIFF and BigTIFF metadata parsing, byte order, IFD traversal,
  dimensions, bands, sample type, strip/tile layout, GeoTIFF keys,
  geotransform, CRS basics, NoData, and initial uncompressed window reads.
- OpenUSD FileFormat registration and metadata-only layer authoring at
  `/Raster`, including dimensions, CRS, bounds, geotransform, anchoring, band
  metadata, and source identifier.
- Local packaged `.tif`/`.tiff` stage opening against OpenUSD 26.08.

## File-format arguments

`representation=metadata` is the only representation. `pixelAnchor=area|point`
may supply anchoring only when the source does not declare it.

## Known limitations

- This is metadata authoring, not a DEM mesh, image, tiled payload, converter,
  remote GeoTIFF, or COG optimization release.
- Compression support and broader pixel decoding remain later milestones.
- The release probe uses a 2x2 synthetic local fixture and does not claim
  large-raster performance or remote byte selectivity.

## Build requirements

CY2026 / OpenUSD 26.08, Python 3.13 for plugin tests, CMake, Ninja, and a C++17
compiler matching the runtime ABI. Direct aggregate runtime composition requires
OpenStrata 0.22.8 or newer.

## Dependencies and licensing

Project code is Apache-2.0. OpenUSD is a runtime/build dependency. Optional
libtiff/libgeotiff integration is not part of the default release product.
`LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md` define distribution terms.

## Verification

The core-only lane, fixture determinism, workspace CTest, FileFormat L0-L4,
product verification, packaged probe, and repeatable package inventory are the
release gates.
