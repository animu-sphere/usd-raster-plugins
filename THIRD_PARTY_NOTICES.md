# Third-Party Notices

This file records third-party software and test data distributed with or
referenced by this repository. The Apache-2.0 license in the repository root
applies to the original project code only; it does not replace the licenses
listed below.

No third-party source is vendored into this repository today. The entries
below record dependencies that are linked or required at runtime, and the
obligations that attach to a binary release. A revision or license change here
updates [NOTICE](NOTICE) and the package verification in the same pull
request; that is invariant 14 of
[the workspace contract](docs/architecture/WORKSPACE.md).

## OpenUSD

OpenUSD is a required runtime dependency for the OpenUSD authoring library, the
FileFormat Plugin bundle, and the converter. It is not vendored by this
repository, and the core libraries build and test without it. Follow the
license and notice requirements of the OpenUSD distribution used to build and
ship a plugin bundle.

## libtiff

`usdGeoTiff` will own a libtiff integration as its private decoding backend;
see [the workspace contract](docs/architecture/WORKSPACE.md). The version is
pinned when milestone 2 selects it, and the license obligations for a binary
release are recorded in
[docs/guides/DISTRIBUTION.md](docs/guides/DISTRIBUTION.md) at that point.
libtiff is distributed under a permissive MIT-style license.

## GDAL

GDAL is never linked into a production target. It may appear only in optional
test targets as a comparison oracle, and it therefore carries no redistribution
obligation for a released binary. See
[ADR-0007](docs/adr/0007-gdal-not-a-core-dependency.md).

## Test fixtures

Test fixtures are generated by `tools/generate_fixtures.py` from code in this
repository, not derived from third-party data. Any future fixture taken from an
external source is recorded here with its provenance and license before it is
used.
